# Claude-Bereich

Hier liegt alles, was Claude Code für dieses Projekt braucht – getrennt von
Daten, Anwendung und Dokumentation.

| Pfad | Inhalt |
| --- | --- |
| `../CLAUDE.md` | Projektgedächtnis. Muss im Wurzelverzeichnis liegen, damit es automatisch geladen wird; verweist auf diesen Ordner. |
| `skills/beleg-aufnehmen/SKILL.md` | Geführter Ablauf, um einen neuen Beleg in das Archiv aufzunehmen. |
| `settings.json` | Freigaben für die Befehle, die dieses Projekt ohnehin ständig braucht. |
