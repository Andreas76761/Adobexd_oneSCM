# Version 1.18.0 – Editor, Fassungen, Gliederung

Aus der Arbeit mit echten Systemscreens: der Editor muss dort sein, wo das
Bild ist, eine Bearbeitung darf die vorige nicht ersetzen, und jedes Bild
braucht seine Stelle in der Gliederung.

## Der Editor ist dort, wo das Bild ist

| von wo | wie |
| --- | --- |
| Ansicht Aufnahme | **Im Editor öffnen** an der zuletzt gemachten Aufnahme |
| Eingang | **Im Editor bearbeiten** auf jeder Karte |
| Portalnavigation | **Editor** (hieß bis 1.17.0 „Markieren“) |

Geladen wird immer das Original. Bearbeitet wird nie eine Bearbeitung – wer
auf einer Fassung aufsetzen will, öffnet sie ausdrücklich.

## Fassungen statt einer Kopie

Bis 1.17.0 gab es ein Original und *eine* bearbeitete Fassung; die nächste
Bearbeitung überschrieb sie. Jetzt legt jedes Sichern eine weitere Fassung
daneben:

```
AUF-2026-001
├── Original           17.10.2026, 09:05
├── Fassung 1          09:07 · 3 Marken   [Öffnen] [Verwerfen]
└── Fassung 2          09:12 · 5 Marken   [Öffnen] [Verwerfen]
```

**Öffnen** holt die Marken einer Fassung zurück auf die Arbeitsfläche – man
arbeitet weiter und sichert als nächste Fassung. **Verwerfen** entfernt eine
Stufe. Das Original lässt sich nicht verwerfen; es ist der Bezugspunkt.

Ein Stand aus 1.17.0 (`bild_markiert`) wird als Fassung 1 gelesen, damit
nichts verlorengeht.

## Gliederung und Zeitstempel

Kapitel und Unterkapitel stehen als Felder im Kopf des Editors. Die Seite
schlägt die nächste freie Unternummer im Kapitel vor; gesetzt wird sie von
Hand, denn die Reihenfolge einer Anleitung kennt nur der Mensch.

Unter das Bild kommt ein Streifen:

```
2.3  ·  Bestellübersicht mit Kundendaten  ·  17.10.2026, 08:14
```

Er wird **angesetzt, nicht übergelegt**: verdeckt wäre er unbrauchbar, und
verdecken soll hier nur, was unkenntlich gemacht wurde. Abschaltbar über
**Nummer und Zeitstempel ins Bild**.

Dieselbe Nummer steht danach auf der Karte im Eingang, im Kontaktbogen und
über den Baustein `{kapitel}` im Namensmuster – dort als `2-3`, weil ein
Punkt im Dateinamen nichts zu suchen hat.
