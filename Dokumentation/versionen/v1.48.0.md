# Version 1.48.0 – Die Sprache der Unterlagen

## Die Bilder konnten Englisch, der Rahmen nicht

Dieselbe Maske gibt es in jeder Sprache – dafür sind die Varianten da. Was
die Seite um die Bilder herum schreibt, war aber immer deutsch: „Seite 2 von
5“, „Stelle im Handbuch“, „Fertig, wenn:“, „Stand“. Für einen Markt außerhalb
DACH ist eine Unterlage damit nicht fertig.

## Eine Wahl im Studio

```
Sprache der Unterlagen  [ English ▾ ]
```

Umgestellt wird alles, was die Seite **selbst schreibt**:

| Ort | deutsch | englisch |
| --- | --- | --- |
| Deckblatt | Inhalt, Stelle im Handbuch, Bilder, Stand | Content, Section in the manual, Images, As of |
| Kopf- und Fußzeile | Seite 2 von 5 | Page 2 of 5 |
| Handbuch | Benutzerhandbuch, Abschlusskriterium, Folge: | User manual, Completion criterion, Sequence: |
| Word-Handbuch | Fertig, wenn:, Schritt 3 | Done when:, Step 3 |
| Fortschrittsblatt | 87 von 1123 Stellen belegt | 87 of 1123 sections covered |
| Dokument | `<html lang="de">` | `<html lang="en">` |

## Was nicht übersetzt wird

**Die Inhalte.** Titel, Notizen und die Texte der Gliederung stehen so da,
wie sie erfasst wurden. Eine Maschine, die sie überträgt, würde behaupten,
sie verstünde sie – und ein Handbuch, in dem der Rahmen englisch und der Satz
darunter falsch übersetzt ist, ist schlechter als eines, das offen zweisprachig
ist. Für eine andere Sprache gibt es zwei Wege, die beide auf eine
Entscheidung von Menschen hinauslaufen:

* die **Varianten** (F-46): dieselbe Maske, in der anderen Sprache
  aufgenommen und verbunden,
* die **eigenen Texte** (F-65): im Haus geschrieben, aus Word zurückgelesen.

**Die Oberfläche.** Sie bedient das Team, das die Unterlagen baut; die
Unterlagen gehen in den Markt. Eine Übersetzung der Oberfläche wäre ein
eigener Schritt – mehrere hundert Texte in elf Ansichten – und ist hier
bewusst nicht enthalten.

## Eine weitere Sprache

`WORTE` im Kern trägt je Sprache eine Liste von Schlüsseln. Eine dritte
Sprache ist ein Eintrag mehr; was dort fehlt, fällt auf Deutsch zurück, es
bleibt also nie etwas leer. Angeboten werden heute Deutsch und English.
