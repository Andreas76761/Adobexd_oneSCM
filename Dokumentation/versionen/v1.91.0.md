# Version 1.91.0 – Ein französischer Quick Guide mit deutschem Bild

Eine Strecke lässt sich in einer anderen Sprache ausgeben: je Schritt wird
das Bild gegen sein Gegenstück getauscht. Wo keines vorliegt, bleibt das
bisherige stehen – das ist richtig so, denn ein fehlendes Bild wäre
schlechter als ein fremdsprachiges. **Gesagt werden muss es trotzdem.**

Nachgefahren mit zwei Schritten, von denen nur der erste eine französische
Entsprechung hat:

```
Umgestellt auf fr: A1-fr -> A2-de
fehlt: [{ nummer: 2, aufnahme: "A2-de", titel: "Formular" }]

Auftrag: { …, "kennungen": ["A1-fr","A2-de"] }
Nennt der Plan die Lücke? NEIN
```

`streckeInVariante()` **weiß** es und gibt es zurück. Das Designstudio
nennt es seit jeher in seiner Meldung: *„1 Schritt(e) ohne Entsprechung: 2"*.
Der Plan des Registers Output warf die Liste weg, und das Register sagte
nichts.

Das ist genau dort schlimm, wo Output seinen Zweck hat: es rechnet den
**ganzen Satz** Dokumente auf einmal. Wer zwanzig Quick Guides in fünf
Sprachen erzeugt, erfährt in keinem einzigen, welche davon gemischt sind.

## Was jetzt gesagt wird

`ausgabeLuecken()` gibt die Schritte ohne Entsprechung; jeder Auftrag im
Plan trägt sie als `luecken`. Im Register stehen sie an zwei Stellen:

* **In der Zeile** – eine Marke „1 ohne Entsprechung" neben den Labels, mit
  den betroffenen Schritten im Titel, dazu ein Streifen in Warnfarbe am
  Zeilenanfang.
* **In der Meldung nach dem Erzeugen** – „… · 2 Dokument(e) mit 3
  Schritt(en) ohne Entsprechung – dort steht das Bild der Ausgangssprache."
  Die Meldung steht dann als Warnung da, nicht als Erfolg.

**Nur Strecken können lücken.** Ein Kapitel filtert nach dem Labelwert;
dort erscheint ein Bild der falschen Sprache gar nicht erst. Die Prüfung
hält das fest, damit niemand die Lücke später auch für Kapitel „repariert".

## Das Dokument selbst trägt nichts

Anders als bei der internen Fassung (1.83.0) bekommt das Blatt keinen
Vermerk. Eine interne Fassung darf nicht aus dem Haus; ein gemischtes
Dokument ist ein Mangel an Vollständigkeit, kein Vertrauensbruch. Es wäre
außerdem dieselbe Entscheidung, die das Designstudio seit jeher trifft:
dort steht die Lücke in der Meldung, nicht auf dem Blatt.

## Ein Fehlschlag aus einem fremden Bereich

Der volle Durchlauf meldete einmal:

```
✗ Adresszeile trägt den Zustand und stellt ihn wieder her
      Suchbegriff fehlt in der Adresse
```

Einzeln bestand die Prüfung zweimal. Das ist der Punkt, an dem man „Flake"
sagt und weitergeht – hier war es ein echtes Wettrennen:

```js
await seite.fill('#suche', 'formular');
await seite.click('.segment button[data-archiv="alle"]');
await seite.waitForFunction(() => location.hash.includes('a=alle'));
wahr(hash.includes('q=formular'), …);
```

Die Suche schreibt die Adresse **gedrosselt**, der Klick auf das Segment
sofort. Wer nur auf `a=alle` wartet, prüft `q=formular` mitunter, bevor es
geschrieben ist. Gewartet wird jetzt auf beides. Eine echte Regression –
`q` wird nie geschrieben – läuft weiterhin in den Zeitablauf.

## Grenzen

* Gezählt werden **Schritte**, nicht Bilder: ein Schritt mit zwei Bildern,
  von denen eines keine Entsprechung hat, zählt einmal. Das ist die
  Einheit, in der das Designstudio schon immer gesprochen hat.
* Die Lücke steht im Register, nicht in der Datei. Wer die Dokumente
  weitergibt, ohne hingesehen zu haben, gibt gemischte weiter.
