# Version 1.67.0 – Elf Bilder, eine Stelle

1.66.0 fuhr den Umlauf einer Word-Datei in die **Gliederung** zurück und fand
dort einen Absatz ohne Namen. Dieselbe Datei kann auch den anderen Weg
nehmen: über das Register **Import** zurück in die Galerie. Dieser Weg wurde
nie gegangen.

## Die Probe

```
=== handbuch.docx (615 kB) ===
Meldung: 11 Bilder aus 1 Datei gelesen.
Verschiedene Folientexte: 1 von 11
   Dokument :: Benutzerhandbuch 7 Zahlungsdaten, Dokumente und Unterschrift …
Stelle aus dem Text: 11 von 11 Bild(ern) eine Stelle zugeordnet.
Verschiedene Stellen: 1 (7.5)
```

Elf Bilder kommen an – gut. Sie tragen **einen** Text, nämlich das ganze
Dokument. Und „Stellen aus dem Folientext" meldet darauf **11 von 11
zugeordnet**, ohne Einschränkung, und setzt alle elf auf **7.5**.

Zehn davon sind falsch. Die Meldung sagt nichts davon.

**Eine Fehlmeldung ist schlimmer als keine Zuordnung.** Wer „0 von 11, der
Text gab sie nicht her" liest, trägt die Stellen von Hand nach. Wer „11 von
11" liest, drückt auf Übernehmen.

## Die Ursache

`officeFolien` liefert die Textträger eines Office-Archivs. Bei PPTX ist das
je Folie einer – darum steht dort der richtige Text neben dem richtigen Bild.
Bei DOCX ist es **einer für das ganze Dokument**:

```js
const wort = finde('word/document.xml');
if (wort) return [{ nummer: 1, name: 'Dokument', xml: wort, rels: … }];
```

Das ist nicht falsch: ein Word-Dokument *ist* ein Dokument. Es ist nur kein
Foliensatz, und der Import behandelt es wie einen.

Dass es niemandem auffiel, liegt an der Prüfdatei: sie trägt **ein** Bild und
**einen** Satz. Bei einem Bild ist „der Text des Dokuments" und „der Text
neben dem Bild" dasselbe. Der Unterschied beginnt beim zweiten.

## Die Behebung

`wordAbschnitte(xml, rels)` teilt ein Dokument an seinen Überschriften: jede
beginnt einen Abschnitt, die Absätze und Bilder darunter gehören dazu. Die
Zuordnung Bild → Abschnitt steht im Dokument selbst (`r:embed`, beim älteren
Weg `r:id`); welche Datei eine Kennung meint, sagt die Beziehungsdatei.

Dieselbe Datei danach:

```
Verschiedene Folientexte: 11 von 11
   7.5.1 Dokumentierte Signaturwege :: 7.5.1 Dokumentierte Signaturwege Fertig, wenn: …
   7.5.2 Signaturergebnis           :: 7.5.2 Signaturergebnis Fertig, wenn: …
Verschiedene Stellen: 11 (7.5.1, 7.5.2, 7.5.3, 7.5.4, 7.6.1, 7.6.2 …)
```

Elf Bilder, elf Stellen. Der Kreis ist zu: **Gliederung → Word-Handbuch →
Import → Galerie → Gliederung.**

## Was absichtlich bleibt

* **Nennt der Text des Dokuments kein einziges Bild**, bleibt es beim einen
  Träger. Ein fremdes Programm kann Bilder anders einbinden; dann sind
  Abschnitte ohne Bilder nutzlos, und die Bilder gingen in den Rest „ohne
  Folie". Lieber der alte Weg als ein leerer neuer.
* **Ein Dokument ohne Überschrift** ist ein Abschnitt und heißt „Dokument" –
  genau wie bisher.
* **Die Präsentation** bleibt, wie sie ist. Der Bildschirmablauf als `.pptx`
  liefert beim Umlauf drei Blätter als Bild und keinen Text; „0 von 3
  zugeordnet" ist dort die richtige Antwort und steht auch so da.

## Der Befund hinter dem Befund

Zwei Fassungen hintereinander, zwei Fehler, dieselbe Form:

| | 1.66.0 | 1.67.0 |
| --- | --- | --- |
| Weg | Word → Gliederung | Word → Galerie |
| Fehler | 15 von 15 Stellen angeboten | 11 von 11 auf dieselbe Stelle |
| Ursache | ein Absatz ohne Namen | ein Dokument ohne Teilung |
| Warum keine Prüfung | Schreiber und Leser je für sich geprüft | die Prüfdatei hatte **ein** Bild |

Beide Male war nichts falsch *programmiert*. Beide Male lag der Fehler im
Raum **zwischen** zwei geprüften Hälften – und beide Male war die Prüfdatei
zu klein, um den Unterschied zu zeigen.

Darum trägt `Testing/hilfen/dateien.mjs` jetzt ein Word-Handbuch mit **zwei**
Kapiteln und zwei Bildern. Eine Prüfdatei mit einem Element prüft die Zahl
eins, nicht die Regel.

## Grenzen

* Geteilt wird an **Heading1–3**, wie die Seite sie schreibt. Ein Dokument,
  das Überschriften nur fett setzt statt sie als Überschrift zu kennzeichnen,
  bleibt ein Abschnitt. Das ist dieselbe Grenze wie beim Rückweg (F-65) und
  derselbe Grund: ohne Vorlage kein Name.
* Ein Bild, das zweimal im Dokument steht, kommt einmal – beim ersten
  Abschnitt, der es nennt.
* Der Umlauf wurde mit Dateien gefahren, die die Seite selbst geschrieben
  hat. Was Word aus einem Dokument macht, das jemand dort bearbeitet und
  speichert, steht hier nicht.
