# Version 1.20.0 – Volle Auflösung und Rückgängig

Zwei Punkte aus der Praxis: das Abdecken muss sich zurücknehmen lassen, und
beim Hineinzoomen darf die Schrift nicht zu Matsch werden.

## Geprüft: unkenntlich machen

| Frage | Antwort |
| --- | --- |
| Bereich auswählen? | ja – Rechteck aufziehen, Werkzeug „Unkenntlich machen“ |
| Wird der Bereich wirklich verändert? | ja – eine Prüfung vergleicht die Bildpunkte davor und danach und sieht nach, dass außerhalb nichts gemalt wurde |
| Rückgängig? | **neu**: `Strg+Z`, `Strg+Umschalt+Z` für Wiederholen, dazu zwei Knöpfe |
| Als Bild speichern? | **neu**: `…_blurrt_<Nr>.png` statt `…-markiert.png` |

Abgedeckt wird weiterhin durch Herunterrechnen auf ein Raster, nicht durch
einen Weichzeichner: was dabei verloren geht, ist weg.

## Volle Auflösung

Bis 1.19.0 wurde jede Aufnahme auf 1100 Bildpunkte heruntergerechnet und als
JPEG abgelegt. Das war für die Liste richtig und für den Zweck falsch: eine
Oberfläche mit 11-Punkt-Schrift ist danach nicht mehr lesbar.

Jetzt gilt:

| wo | was |
| --- | --- |
| Browserdatenbank `screenarchiv`, Speicher `bilder` | das Bild in voller Auflösung, verlustfrei als PNG |
| `localStorage` | eine Vorschau mit 760 Bildpunkten, JPEG |
| Editor | lädt das volle Bild, rechnet darauf, nennt die Auflösung |
| Ablage in Ordner und Datei | volle Auflösung |

Der Grund für die Teilung: der `localStorage` fasst rund fünf Megabyte – ein
einziger Bildschirm in voller Auflösung wäre schon ein Zehntel davon. Die
Datenbank fasst ein Vielfaches. Fehlt sie (Privatfenster, gesperrter
Speicher), bleibt die Vorschau; die Seite sagt dann nichts Falsches, sie
zeigt nur weniger.

## Behoben

Das Ablegen des vollen Bildes läuft nebenher. Es ersetzte dabei die Aufnahme
im Eingang durch eine Kopie – und löschte so die Herkunft, die das
Ausschneiden ihr unmittelbar davor angehängt hatte. Jetzt wird die vorhandene
Aufnahme ergänzt statt ersetzt, und die Herkunft wird beim Schreiben neu
gesucht statt auf einer alten Fassung gesetzt. Gefunden hat das eine
bestehende Prüfung.
