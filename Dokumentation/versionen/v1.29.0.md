# Version 1.29.0 – Verzeichnis

Der Eingang liegt im `localStorage`, die Bilder in der Browserdatenbank. Wer
die Browserdaten löscht, löscht beides. Dauerhaft wird eine Aufnahme erst als
Datei – und genau das macht diese Ansicht, für die ganze Galerie auf einmal.

## Was in den Ordner geht

| Datei | Inhalt |
| --- | --- |
| `…/<name>.png` | das Bild in voller Auflösung, Beipackzettel im PNG |
| `…/<name>.json` | der Beipackzettel daneben |
| `index.json` | Übersicht: Datei, Stelle, Thema, Labels, Maße, Einfuhr |
| `index.csv` | dieselbe Übersicht für eine Tabelle |
| `strecken.json` | alle Strecken im Format der Seite |
| `prozesse/<name>.bpmn` | je Strecke der Prozess aus 1.25.0 |

Der Zettel steckt zweimal da: im PNG (wer nur das Bild weitergibt, gibt ihn
mit) und als Datei daneben (die liest jedes Werkzeug, einen PNG-Abschnitt
nicht).

## Die Ordnung ist das Muster

```
{sparte}/{sprache}/{kapitel}/{rolle}/{datum}_{kennung}_{titel}
→ pkw/de/6-2/dealer/2026-10-17-auf-2026-001-vorlagenliste-oeffnen.png
```

Das ist die Ordnung, in der später gesucht wird: Sparte, Sprache, Kapitel,
Rolle – und im Dateinamen das Datum. Zur Verfügung stehen `sparte, sprache,
rolle, markt, kapitel, thema, datum, jahr, monat, kennung, titel, projekt,
kategorie`. Ein Schrägstrich macht einen Ordner; die Unterordner entstehen
beim Schreiben.

Zwei Entscheidungen, die man merkt:

* **Was fehlt, wird benannt.** Ein Bild ohne Sprache landet in
  `ohne-sprache`, nicht zwischen den deutschen. Eine leere Stelle im Pfad
  wäre eine Lüge.
* **Ein unbekannter Platzhalter bleibt stehen.** `{quatsch}` wird zu
  `quatsch` im Namen, nicht zu nichts – sonst fiele ein Tippfehler im Muster
  nie auf.

## Erst der Plan, dann die Datei

Die Vorschau zeigt jede Datei mit ihrem Pfad, **bevor** eine entsteht. Der
Plan kommt aus dem Kern (`verzeichnisPlan`) und ist dort geprüft: Reihenfolge
nach Gliederung, Dateien je Schalter, und gleiche Pfade bekommen eine Nummer –
zwei Bilder mit gleichem Titel am gleichen Tag dürfen sich nicht gegenseitig
überschreiben.

## Wenn etwas scheitert

Eine Datei, die nicht geschrieben werden kann, hält die übrigen nicht auf. Am
Ende steht, was liegt und was fehlte:

> In „Screens“ liegen nun: 24 Bilder, 24 Beipackzettel, 3 Prozesse,
> Übersicht, Strecken. Nicht geschrieben wurden 1: pkw/de/9-1/x.png (kein
> Bild vorhanden)

Eine halbe Galerie auf der Platte ist mehr wert als keine.

## Grenze

Ordnerzugriff gibt es nur in Chromium (Chrome, Edge) – das ist eine Grenze
des Browsers, nicht der Seite. Fehlt er, sagt die Ansicht es und nennt den
Weg über „Als JSON sichern“ im Eingang.
