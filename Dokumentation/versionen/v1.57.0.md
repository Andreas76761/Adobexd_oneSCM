# Version 1.57.0 – Aus dem Video wird eine Strecke

Das Register Video (1.55.0) nimmt Einzelbilder aus einem Bildschirmvideo und
legt sie in den Eingang. Dabei ging etwas verloren, das die Datei schon
hatte: **die Reihenfolge.**

## Ein Bildschirmvideo *ist* eine Klickstrecke

Wer eine Maske nach der anderen aufnimmt, hat damit eine Klickstrecke
aufgezeichnet – Schritt für Schritt, in der richtigen Folge. Bisher landeten
die Bilder einzeln im Eingang, und wer daraus eine Strecke wollte, baute sie
von Hand nach: zwanzigmal eine Aufnahme im Auswahlfeld suchen und anhängen.
Die Reihenfolge stand zweimal da – im Video und im Kopf dessen, der sie
nachbaut.

Neben „Gewählte übernehmen“ steht darum jetzt **„Als Strecke übernehmen“**:

| | |
| --- | --- |
| Die Bilder | gehen in den Eingang wie bisher |
| Zusätzlich | entsteht eine Strecke, benannt nach der Videodatei |
| Je Bild | ein Schritt, in der Reihenfolge des Films |
| Der gedeutete Text | wird zur Anweisung des Schritts |

Daraus macht das Designstudio den **Quick Guide** – eines der vier
Dokumente, um die es in diesem Projekt geht.

## Was dabei nicht erfunden wird

* **Ein Bild ohne Text bekommt keinen.** Der Schritt steht da, die Anweisung
  bleibt leer, und die Meldung sagt wie viele: *„3 Bilder im Eingang, dazu
  die Strecke ‚Vertrag anlegen' mit 3 Schritten – 1 davon ohne Anweisung,
  die stehen in der Strecke zum Eintragen.“*
* **Die Reihenfolge kommt aus der Zeit im Video**, nicht aus der Reihenfolge
  der Karten. Wer Bilder abwählt, bekommt die übrigen in ihrer Folge.
* **Ein Bild, das nicht in den Eingang kam**, wird kein Schritt – eine
  Strecke verweist auf Kennungen, und eine Kennung, die es nicht gibt, wäre
  ein Platzhalter ohne Grund.

## Die Strecke entsteht nach den Bildern, nicht davor

Eine Strecke verweist auf Aufnahmen über ihre Kennung. Also werden erst die
Bilder übernommen, und erst wenn das gelungen ist, entsteht die Strecke aus
dem, was tatsächlich im Eingang liegt. Scheitert die Übernahme, gibt es
keine halbe Strecke mit leeren Schritten.

## Kern

```js
streckeAusVideo(bilder, name, zeit)   // Schritte in zeitlicher Folge
streckenNameAusVideo('Vertrag_anlegen.mp4')  // → 'Vertrag anlegen'
```

Beide ohne Oberfläche und ohne Browser geprüft. `streckeAusVideo` sortiert
eine **Kopie** – die übergebene Liste bleibt, wie sie war.

## Damit ist die Kette geschlossen

```
Clipchamp → MP4 → Video → Bilder → Strecke → Designstudio → Quick Guide
```

Vorher riss sie zwischen „Bilder“ und „Strecke“, und die Lücke wurde von
Hand gefüllt.
