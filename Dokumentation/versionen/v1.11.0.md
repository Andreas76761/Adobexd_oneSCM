# Version 1.11.0 – Übernahme aus dem Ordner

Erster von elf Punkten aus der Bestandsaufnahme „was fehlt“: der größte Bruch
in der Anwendung.

## Was fehlte

Die Ablage war eine Einbahnstraße. Seit 1.9.0 schreibt die Seite neben jedes
Bild einen Beipackzettel, seit 1.10.0 kann sie ihn anzeigen – zurückholen
konnte sie ihn nicht. Nach einer Pause lag die Arbeit auf der Platte, und die
Anwendung wusste nichts mehr davon. Wer weiterarbeiten wollte, musste die
Metadaten von Hand neu eintippen.

## Der Rückweg

In der Zettelschau steht **In den Eingang übernehmen**. Daraus entsteht eine
Aufnahme wie jede andere:

| Feld | Herkunft |
| --- | --- |
| Titel, Projekt, Seite, Kategorie, Status, Rolle, Begriffe, Notiz, Autor, Browser | aus dem Zettel |
| Datum, Erfassungszeitpunkt | aus dem Zettel – nicht der Tag der Übernahme |
| Ausschnitt, Quelle | aus dem Zettel, nur vollständige Maße |
| Kennung | neu vergeben, nach dem **Aufnahmejahr** |
| Bild | aus der Bilddatei, als JPEG neu gefasst |

Fehlt eine Angabe, bleibt sie leer. Es wird nichts geraten: ein halber
Ausschnitt (`{breite: "x"}`) wird zu `0 × 0`, nicht zu einer erfundenen Zahl.

## Warum das Bild neu gefasst wird

Der Eingang liegt im `localStorage`, und der ist knapp. Ein PNG aus dem Ordner
ist schnell 1–2 MB; nach fünf Dateien wäre Schluss. Übernommene Bilder werden
darum wie eigene Aufnahmen als JPEG abgelegt. Das Original bleibt im Ordner
unangetastet – die Datei auf der Platte ist weiterhin die beste Fassung.

## Nur einmal

Jede übernommene Aufnahme trägt ihre Herkunft:

```json
"herkunft": {
  "ordner": "Bildschirmfotos",
  "datei": "schirm-001.png",
  "zettel": "schirm-001.json",
  "uebernommen_am": "2026-10-17T10:00:00.000Z"
}
```

Daran wird die Datei wiedererkannt – über Ordner und Namen, Groß- und
Kleinschreibung egal, auch nach einem Neuladen. Die Kachel im Ordnerband trägt
dann die Kennung, und der Knopf heißt **Im Eingang zeigen**. Erkannt wird die
Datei, nicht ihr Inhalt: wird dieselbe Datei im Ordner überschrieben, gilt sie
weiter als übernommen.

## Grenzen

* Ein Bild **ohne** Zettel lässt sich nicht übernehmen – es wäre ein Bild ohne
  Zusammenhang. Ein unlesbarer Zettel ebenso; die Schau sagt das.
* Die Herkunft hängt am Dateinamen. Wird die Datei umbenannt, gilt sie als neu.

## Umfang

* Neue Kennung F-28
* Neu im Kern: `aufnahmeAusZettel`, `findeUebernahme`, `herkunftSchluessel`
* 5 neue Prüfungen, zusammen **196**
