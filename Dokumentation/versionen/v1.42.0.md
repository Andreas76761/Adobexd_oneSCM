# Version 1.42.0 – Der Agent Sprache

## Die drei Agenten prüften nicht, was dasteht

Roter Faden, Audit und Empfehlung sehen auf Vollständigkeit, Zuordnung und
Reihenfolge. Keiner von ihnen liest die Texte. In einem Handbuch für Händler
steht dann an einer Stelle „Dealer“, an der nächsten „Händler“; „oneSCM“ ist
dreimal anders geschrieben; und unter einem Bild mit dem Label *Deutsch*
steht ein englischer Titel. Das fällt beim Lesen auf – also spät.

## Vier Prüfungen, alle nach Regeln

| Prüfung | Was sie findet |
| --- | --- |
| **Wortliste** | ein Wort, für das die Liste ein anderes vorsieht: „Dealer“ → „Händler“ |
| **Schreibweise** | „OneSCM“ statt „oneSCM“ |
| **Sprache gegen Label** | englischer Titel an einem Bild mit Label *Deutsch* |
| **Uneinheitliche Schreibweise** | dasselbe Wort in den Titeln verschieden geschrieben, mit Häufigkeit je Form |

Geprüft werden Titel, Notiz, Begriffe, die Schritttexte der Strecken und –
wenn es sie gibt – die **Lesungen aus dem Register OCR**. Damit prüft der
Agent nicht nur, was über das Bild geschrieben wurde, sondern auch, was im
Bild steht.

## Zwei Vorsichtsmaßnahmen

**Eine Regel, die nur die Schreibweise meint**, achtet auf Groß und Klein.
Sonst träfe „OneSCM → oneSCM“ auch jedes richtig geschriebene „oneSCM“ und
jeder Befund wäre falsch. Erkannt wird das daran, dass beide Seiten der Regel
aus denselben Buchstaben bestehen.

**Die Sprache eines Textes wird geraten, nicht gemessen** – an häufigen
Wörtern (`der`, `und`, `für`; `the`, `with`, `from`). Ohne deutliches
Übergewicht gibt es keine Antwort und damit keinen Befund; aus einem Titel
wie „Status“ wird nichts geschlossen.

## Die Wortliste gehört dem Betrachter

Sie steht in der Ansicht Prüfung, aufklappbar, und sieht so aus:

```
# Zeilen mit Raute werden übersprungen
Dealer -> Händler (de)
Market -> Markt (de)
Händler -> Dealer (en)
OneSCM -> oneSCM
Mercedes Benz -> Mercedes-Benz
```

Ohne Sprache in Klammern gilt eine Regel überall. Eine Regel **mit** Sprache
gilt nur für Bilder, die diese Sprache tragen – an einem Bild ohne Label
greift sie nicht, denn welche Sprache dort gelten soll, weiß niemand.

Die Liste liegt in `screenarchiv:woerter`, überlebt das Neuladen, und
„Vorgabe wiederherstellen“ holt den Anfangsbestand zurück. **Was nicht in der
Liste steht, wird nicht geprüft** – der Agent hat keine Meinung, nur Regeln.
